PROJECT OVERVIEW
================================================================================
Build a functional frontend-only MVP that demonstrates core workflows without
requiring backend infrastructure. This allows:
- Quick stakeholder feedback on UI/UX
- Validation of workflows and user journeys
- Team training on the interface
- Early problem identification
- No database/server setup required

TECHNICAL APPROACH
================================================================================
- Frontend: React + TypeScript + Vite
- State: localStorage for data persistence
- Mock API: Simulate backend responses with delays
- Data: Pre-generated realistic Bangladeshi data
- No Backend: Pure frontend application
- No Database: All data in memory + localStorage

BRANCH STRATEGY
================================================================================
Branch Name: mvp-demo
Based on: dev branch
Purpose: Standalone MVP that can be demoed

After MVP approval, migrate learnings to main Phase 1 development.

Mock Data Strategy:
-------------------
1. Initial Load:
   - Generate mock data on first app load
   - Store in localStorage
   - Include reset data button

2. Data Persistence:
   - All changes saved to localStorage
   - Survives page refresh
   - Can be exported/imported

3. ID Generation:
   - Patient: PID-0001, PID-0002, etc.
   - OPD: OPD-0001, OPD-0002, etc.
   - Invoice: INV-0001, INV-0002, etc.
   - Sequential numbering

4. Mock API Delays:
   - Simulate network delays (300-500ms)
   - Show loading states
   - Realistic user experience

COMMANDS TO START
================================================================================

1. Create MVP Branch:
   git checkout -b mvp-demo

2. Initialize Project:
   pnpm create vite mvp-frontend -- --template react-ts
   cd mvp-frontend
   pnpm install

3. Install Dependencies:
   pnpm add react-router-dom
   pnpm add react-hook-form @hookform/resolvers zod
   pnpm add date-fns
   pnpm add react-to-print
   pnpm add lucide-react
   pnpm add -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p
   pnpm add @headlessui/react

4. Start Development:
   pnpm run dev

5. Open Browser:
   http://localhost:5173
